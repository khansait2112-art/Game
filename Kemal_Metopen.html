Jejak Harta Peneliti

Treasure Hunt 3D · Metodologi Penelitian PAI

Cara main
  • Jelajahi hutan, danau, dan pegunungan Pulau Metodologi. Ada 5 lokasi, satu untuk tiap bahan kajian di RPS.
  • HP: geser joystick kiri untuk berjalan, geser layar untuk memutar kamera, tombol Lompat untuk melompat.
  • Laptop: WASD atau panah untuk berjalan, seret mouse untuk memutar kamera, Spasi untuk melompat, E untuk menggali.
  • Ikuti sorotan cahaya emas dan panah tujuan. Dekati tanda X merah lalu tekan Gali untuk membuka tantangannya.
  • Tantangan selesai, peti terbuka dan kamu dapat koin. Semua X di satu lokasi selesai, kamu dapat permata dan satu huruf petunjuk.
  • Kumpulkan 5 huruf, lalu daki Puncak Harta untuk membuka peti harta karun.
  • Tidak ada batas waktu. Salah boleh mencoba lagi, tapi nilai rapor dihitung dari percobaan pertama.
